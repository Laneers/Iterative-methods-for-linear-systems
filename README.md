# Iterative-methods-for-linear-systems

Реализация на C++ итерационных методов решения систем линейных алгебраических уравнений **Ax = b**:

- метод простой итерации (с подбором параметра τ);
- метод Якоби;
- метод Зейделя (для трёхдиагональных систем);
- метод релаксации (SOR, для трёхдиагональных систем, с подбором параметра ω).

Для каждого метода программа проверяет условия сходимости (нормы матрицы перехода), считает априорную оценку числа итераций, выполняет итерации до заданной точности и сохраняет результат в текстовый файл.

## Теория

Все методы приводят систему к виду **x = Cx + y** и строят последовательность приближений x⁽ᵏ⁺¹⁾ = C·x⁽ᵏ⁾ + y. Начальное приближение x⁽⁰⁾ = y.

| Метод | Итерация |
|---|---|
| Простая итерация | `x⁽ᵏ⁺¹⁾ = (E − τA)·x⁽ᵏ⁾ + τb` |
| Якоби | `xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − Σ_{j≠i} aᵢⱼ·xⱼ⁽ᵏ⁾) / aᵢᵢ` |
| Зейдель (трёхдиагональная матрица) | `xᵢ⁽ᵏ⁺¹⁾ = (dᵢ − aᵢ·xᵢ₋₁⁽ᵏ⁺¹⁾ − cᵢ·xᵢ₊₁⁽ᵏ⁾) / bᵢ` |
| Релаксация (трёхдиагональная матрица) | `xᵢ⁽ᵏ⁺¹⁾ = (1 − ω)·xᵢ⁽ᵏ⁾ + ω·(dᵢ − aᵢ·xᵢ₋₁⁽ᵏ⁺¹⁾ − cᵢ·xᵢ₊₁⁽ᵏ⁾) / bᵢ` |

Здесь `a`, `b`, `c` — нижняя, главная и верхняя диагонали, `d` — правая часть.

**Априорная оценка числа итераций** (для ‖C‖ < 1, в бесконечной норме):

```
k ≥ ( ln ε + ln(1 − q) − ln ρ₀ ) / ln q,    ρ₀ = ‖x⁽¹⁾ − x⁽⁰⁾‖∞
```

Для простой итерации и Якоби `q = ‖C‖∞`. Для Зейделя и релаксации `q = ‖G₂‖∞ / (1 − ‖G₁‖∞)`, где G₁ — нижняя треугольная часть C, G₂ — остальная.

**Параметр τ** для простой итерации: теоретическое значение `τ = 1 / ‖A‖∞`. Программа дополнительно перебирает τ на отрезке `(0, 1.2 · 2/‖A‖∞]` и выбирает значение с наименьшим числом итераций.

**Параметр ω** для релаксации перебирается в диапазоне `[1.0, 2.0)` с шагом 0.05.

## Сборка

**Visual Studio.** Откройте `Iterative-methods.sln`, выберите конфигурацию `Release` и соберите проект (`Ctrl+Shift+B`).

**GCC / Clang.**

```bash
git clone https://github.com/Laneers/Iterative-methods-for-linear-systems.git
cd Iterative-methods-for-linear-systems/Iterative-methods
g++ -std=c++17 -O2 main.cpp SimpleIteration.cpp Jacobi.cpp Seidel.cpp Relaxation.cpp Norms.cpp -o iterative
```

## Запуск и формат входных данных

Программа читает с клавиатуры **имя входного файла без расширения** `.txt`:

```
$ ./iterative
test1
```

Входной файл содержит размерность `n` и расширенную матрицу системы `[A | b]` — `n` строк по `n + 1` числу в каждой (последний столбец — правая часть).

Пример `test1.txt`:

```
4
15 2 -3 7 53
-5 11 2 -3 -90
0 -1 7 4 107
12 0 -6 20 68
```

После работы методов простой итерации и Якоби программа запросит число **N**:

```
Input N: 
```

По нему строится трёхдиагональная система размерности `n = 200 + N`, на которой запускаются методы Зейделя и релаксации.

> Имя входного файла должно иметь вид `testK` (например, `test1`): номер `K` берётся из имени и используется в именах выходных файлов.

## Что делает программа

1. **Простая итерация.** Диагональные элементы приводятся к положительным (строки с отрицательным `aᵢᵢ` умножаются на −1). Затем метод запускается для набора значений τ. Выводятся теоретическое τ и экспериментально лучшее, число итераций и ‖C‖∞ для каждого.
2. **Якоби.** Метод запускается на той же системе из файла.
3. **Зейдель.** Решается трёхдиагональная система размерности `n = 200 + N`: `bᵢ = 4`, `aᵢ = cᵢ = 1`, правая часть `d₁ = 6`, `dᵢ = 10 − 2·(i mod 2)`, `dₙ = 9 − 3·(n mod 2)`.
4. **Релаксация.** Решается та же трёхдиагональная система. Перебираются значения ω, выбирается лучшее (с минимальным числом итераций), и метод запускается с ним ещё раз для записи результата.

Для каждого метода в консоль выводятся нормы ‖C‖₁ и ‖C‖∞, оценка числа итераций и фактическое число итераций до сходимости. Если `‖C‖∞ ≥ 1`, выводится предупреждение, что сходимость не гарантируется.

## Формат выходных файлов

Результаты записываются в файлы вида `<Метод><K>_<точность>.txt`, например `Simple_iteration1_1e-4.txt`, `Jacobi1_1e-4.txt`, `Seidel1_1e-4.txt`, `Relaxation1_1e-4.txt`.

Пример содержимого:

```
-6.99997 7 2 -6 
k_est >= 30.8749
steps = 15
tau = 0.0132032
diff_norm = 3.60116e-05
err_norm = 0.00126837
Norm_l1 C = 0.761567
Norm_inf C = 0.703457
```

| Поле | Значение |
|---|---|
| первая строка | найденное решение x |
| `k_est` | априорная оценка числа итераций |
| `steps` | фактическое число итераций |
| `tau` | параметр τ (только для простой итерации) |
| `diff_norm` | значение критерия остановки на последней итерации |
| `err_norm` | норма невязки `‖Ax − b‖∞` |
| `Norm_l1 C`, `Norm_inf C` | нормы матрицы перехода C |

## Настройка точности и критерия остановки

Точность задаётся в начале `main.cpp`:

```cpp
double EPS = 1e-4;   // допустимо 1e-4 или 1e-7 (от значения зависит суффикс в имени выходных файлов)
double EPS0 = 1e-14; // защита от деления на ноль в относительном критерии
```

По умолчанию итерации прекращаются, когда относительное изменение приближения не превышает EPS:

```
‖x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾‖∞ / (‖x⁽ᵏ⁾‖∞ + EPS0) ≤ EPS
```

В исходниках методов в комментариях оставлены альтернативные критерии остановки (по абсолютной разности, с поправкой `(1 − ‖C‖)/‖C‖`); их можно включить, раскомментировав нужные строки. Максимальное число итераций: `max(1000, 2·k_est)`.

Параметр `flag` в функциях методов переключает режим работы: при `flag = true` выполняется фиксированное число итераций, равное априорной оценке `k_est + 1`.
